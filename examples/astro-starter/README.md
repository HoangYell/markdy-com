# Markdy + Astro Starter

Minimal starter template demonstrating how to embed interactive, animated [Markdy](https://markdy.com) architecture diagrams inside an [Astro](https://astro.build) project using `@markdy/astro`.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) to view the live animated diagram.

## Build

```bash
npm run build
npm run preview
```
